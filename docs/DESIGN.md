# 功能与实现边界

## 自动安全关注与教师收件箱

新增SafetyAlert模型与增量迁移，保留原三模型和全部原接口。安全消息独立于孩子确认提交的HelpCard；同一会话与消息编号唯一，删除会话时保留教师端必要信息。

明确措辞先由规则记录，再回复系统安全提示，不等待模型；其余由同次聊天中的内部safetySignals结合上下文判断，不增加学生问答步骤。模型证据只能引用学生原话，不能引用助手或编造内容；至少一段来自当前消息，防止仅凭历史内容重复上报。学生响应仍为原三字段，缓存重放同样剥离内部字段。

规则和模型可能误报漏报，不进行心理打分、诊断或确定事实。普通生气/难过不是自动报告依据；否定和引用有反例检查，但不能保证覆盖所有语言。教师须人工核实，不应把提示直接当作处罚依据。

学生首页和对话页提前说明信息流；教师收件箱登录后才可读取，有未读/已读/已跟进状态和10秒轮询，无微信邮件推送。匿名编号仅关联当前会话，无法自动识别真实孩子。不增加姓名收集，不自动删除安全关注消息，正式使用前需由学校确定保存期限与现场跟进方式。以下初版说明中的“仅主动提交”指求助卡，自动消息按本节处理。


| 路径 | 行为 |
|---|---|
| `/` | 选择1—6年级；三个入口分别创建 `listen`、`solve`、`teacher` 匿名会话。 |
| `/chat` | 文字对话；可以切换倾听/想办法。始终有“你理解错了”“找老师”“结束对话”。纠正按钮填入输入框，让孩子补充，不代替孩子发送。 |
| `/help-card` | 不要求聊天。事情经过写一句也可提交，其余四项选填。可以整理草稿、修改、勾选确认后提交。直接访问此页也可选择年级并填写，提交时自动创建匿名会话。 |
| `/teacher/login` | 密码登录。 |
| `/teacher` | 服务端验证登录后才显示工作台；待处理/已处理/全部筛选，分页、刷新和修改状态。只展示已提交卡片，不展示完整聊天。 |

“结束对话”返回首页，不等于删除记录；聊天页另有“删除本次聊天记录”，确认后删除会话和聊天。已提交卡片通过外键 `SetNull` 保留，由教师另行管理。第一版未提供教师删除卡片、自动清理、定时通知或孩子端查看他人卡片的接口。

聊天、未发送文字、待重试请求和求助卡草稿暂存在当前标签页的 `sessionStorage`，刷新可恢复。凭证仅保存在 HttpOnly Cookie，无法通过 JS 读取。关闭标签页通常清除浏览器草稿，但**不会删除服务端数据**。一台浏览器同一站点只保留一个当前学生凭证；重新创建会话会替换凭证，不支持多个学生在同一浏览器中并行使用。


## 实现与数据管理


`src/lib/ai.ts`：服务端模型调用、提示词、JSON校验、明确演示输出、摘录式草稿。`auth.ts`：学生凭证与教师登录；`http.ts`：输入校验、异常、同站检查与单进程限速。`src/app/api`：所有原定接口及退出登录接口。`src/components`：学生交互与教师工作台。`prisma/migrations`：可重复初始化的迁移。

保留原 Prisma 三个模型，为鉴权与重试去重增加 `Session.credentialHash`、`Message.clientMessageId`、`HelpCard.submissionId` 和索引。

AI通过提示词约束不裁决、不逼迫道歉、不强制和解、1—3句且最多一个问题；结构校验无法保证所有生成内容合规或没有误解。页面始终说明其局限，并保留直接找老师入口。伤害关键词只做补充提示，可能误报/漏报，不是安全判断，不能替代成人现场照护。

使用目的已确认为本地或课堂展示。第一版遵循“不收集真实姓名”：没有姓名、班级、联系方式或通知，**教师不能仅凭匿名卡片定位孩子，也无法在线回复该学生**；由有老师在场的展示流程承接。若以后改为真实学生长期使用，需要再确定学校接收/跟进方式、访问范围、账号归属、数据保存与删除期限、监护与隐私安排，以及供应商如何处理儿童输入。当前24小时凭证过期不自动删除服务端数据，草稿与聊天内容也可能包含孩子自行输入的个人信息。

单进程限速/并发锁不跨实例；共享教师密码不是多教师账号系统。SQLite、签名Cookie、保守摘录校验是第一版实现，不代表完成正式上线评估。未增加未授权的姓名收集、积分、测试、排行榜、语音或通知功能。

依赖使用 Next.js 15.5.28 / React 18.3.1 / Prisma 5.22.0，仍为 Next.js App Router + TypeScript + SQLite。原示例的 Next.js 14.2.15 未沿用，15.5.28为官方2026年10月公告中的修复版本：[Next.js官方公告](https://nextjs.org/blog/nextjs-security-update-october-14-2026)。部署前请按当时公告复核更新。
